# Haven recording script

Target: approximately 2:15–2:30, depending on narration and any Live AI latency. English narration. Do not claim real device access or substitute scripted results for live evidence.

## Preparation

- Run `npm run build`, then `npm start`. Open http://127.0.0.1:3000 in a desktop browser, ideally 1440px wide or wider.
- Click **Reset demo**. Keep the simulation and mode badges in view. If recording scripted mode with a configured key, click **Use Scripted demo** in the workspace footer first.
- Use fictional message text. No login, accounts, or devices are required.
- For a shorter recording viewport, scroll down slightly after introducing the badges so the quick prompts and preview are visible.

## Backup / failure handling

If Live AI fails, show **AI unavailable** and say: “The AI request failed. Haven makes that visible and offers a retry. I can explicitly choose the scripted backup.” Click **Use Scripted demo**, name the new mode, and repeat the prompt. Never describe that response as a live model result. Allow extra recording time for this branch; it is not included in the main timing.

Optional, outside the timed script: simulate motion and offline events, then choose **What do we know, and what is still unknown?** Explain that motion does not identify a person and an offline device does not establish danger.
